# Analisis Ketenagakerjaan Kota Cilegon

## Tentang Proyek

Proyek ini menganalisis **tren ketenagakerjaan Kota Cilegon periode 2020–2024** menggunakan **Microsoft Excel**. Analisis mencakup perkembangan angkatan kerja, penduduk bekerja, dan pengangguran berdasarkan data statistik yang tersedia.

Data diolah dan divisualisasikan menggunakan **PivotTable dan PivotChart** untuk melihat perubahan serta tren ketenagakerjaan selama periode tersebut.

## Hasil Utama

* Angkatan kerja mencapai **230.351 orang pada 2022**, kemudian menurun menjadi **204.179 orang pada 2024**.
* Jumlah pengangguran menurun dari **25.976 orang pada 2020** menjadi **12.421 orang pada 2024**.
* Tren pengangguran menunjukkan penurunan yang cukup signifikan selama periode 2020–2024.
